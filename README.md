# TypeBrawl – Typing Fighting Game

Fight by typing fast. Every word is a punch. Free, no install, no server.

## Files
- `index.html` – TypeBrawl (the main game)
- `race.html` – PitLane Typing (the car race version, bonus)

## Publish on GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `race.html` and `README.md` to the root of the repo.
3. Go to Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / `(root)` > Save.
4. After about a minute, your game is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`
   (the race game is at `.../race.html`).

## Customize
- Opponent speed and damage: edit the `LV` table in `index.html`.
- Words: edit the `WORDS` and `SPECIALS` lists.
